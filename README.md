# Mostafa & Hasnaa — Wedding Invitation

A royal digital wedding invitation for **Ahmed & Eman**, matching the look and flow of a cinematic single-page invite: entrance door video, music, countdown, love story, gallery, venue details, RSVP, guestbook, and English/Arabic toggle.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:3847](http://127.0.0.1:3847).

```bash
npm run build
npm run preview
```

## What’s included

- Entrance gate with door video + click-to-open
- Background wedding piano music
- Live countdown to the wedding date
- Auto-scroll presentation mode
- Love story timeline, photo gallery, venue & schedule
- Dress code, RSVP form, blessings guestbook
- English / Arabic (RTL) language switch
- WhatsApp share + Google Calendar / Maps links

## Customize

Edit `index.html` for names, dates, venue, copy, and i18n strings. Replace files in `public/` for the background image (`IMG_6317.jpeg`), favicon (`icon.png`), and door video (`wedding-door.mp4`).
